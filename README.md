# 🏠 La Hueca del Sabor - Página Web Institucional

## 📖 Descripción

Página web institucional para el restaurante de comida rápida colombiana **"La Hueca del Sabor (QÉHVÉ)"**. Landing page con información del negocio, ubicación, redes sociales y catálogo digital.

## 🚀 Características

- ✅ Diseño moderno con efecto neón
- ✅ Información del negocio y horarios
- ✅ Catálogo digital con filtros
- ✅ Mapa de ubicación (Google Maps)
- ✅ Redes sociales (Instagram, Facebook, TikTok)
- ✅ Carrito de compras integrado
- ✅ WhatsApp flotante para contacto
- ✅ Diseño responsive
- ✅ Fondo oscuro con brazas

## 🛠️ Tecnologías

- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
- **Backend:** PHP 8.2
- **Datos:** Archivos JSON
- **Hosting:** InfinityFree
